## ⭐ Featured project

### [Face Recognition → Live Attendance System](https://github.com/mohamadalaamasre-ai/face-recognition-attendance)
Live face recognition on a laptop webcam, extended to person segmentation and a multi-person attendance system with a Streamlit dashboard.

- InsightFace (SCRFD + ArcFace) embeddings, a baseline vs. logistic regression comparison, and gallery-based open-set identification
- Leakage-free split (by video and by identity), FAR / FRR / ROC, and a shortcut-learning test
- YOLO11n-seg person masks colored by identity, about 22 FPS on an RTX 3050
- Tested a pretrained anti-spoofing model and rejected it based on measured APCER / BPCER
